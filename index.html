🔑 FinMind API Token
尚未設定
未登入時每小時只能查 300 次，很容易在連續操作時被擋下來（就是「載入失敗」的主因）。
到 FinMind 官網 免費註冊並驗證信箱後，可取得 token，上限提高到 600 次／小時。
Token 只會存在這台電腦的瀏覽器裡，不會上傳到你的雲端同步資料庫。每台電腦要各自設定一次。
☁ 跨裝置雲端同步 (Firebase)
尚未設定
1. 到 Firebase 主控台 建立免費專案
2. 左側選單「Build → Realtime Database」→ 建立資料庫（先選測試模式即可）
3. 左上角齒輪「專案設定」→「一般」→ 你的應用程式 → 新增網頁應用程式（</> 圖示），複製出現的 firebaseConfig 整段貼上方
4. 每台電腦都要打開同一個網址，並貼上「同一組」設定，資料才會同步在一起
